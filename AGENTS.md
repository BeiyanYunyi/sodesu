# Sodesu

Sodesu is a rewrite of the waline comment system using SolidJS and UnoCSS.

## Directory Structure

- src: sodesu source code
  - src/vendor/waline: waline vendor code, with some code removed
- waline: waline submodule, sync to the latest version, `vendor/waline` should be updated according to `waline/packages/client`.
